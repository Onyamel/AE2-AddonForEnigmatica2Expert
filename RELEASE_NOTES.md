# AE2 Expert Addon 1.3.0 — Minecraft 1.12.2

## English

An AE2 addon for Enigmatica 2: Expert 1.93a. English and Russian are supported through Minecraft's language settings.

This release fixes interface item recovery, unsafe initialization, damaged cell NBT loading, converter energy handling, container input handling and unsupported vertex formats. It also includes bilingual project documentation. Version 1.3.0 replaces the prepared 1.2.1 version number.

Validation: 114 regression checks. The same functional code passed 1415 gameplay/integration checks and 8192 model calls across four threads before renumbering. This does not replace long-term multiplayer testing; see the audit for coverage limits.

Close Minecraft, back up your world and replace the old addon jar with **ae2expert-1.3.0.jar**. Keep one addon version only, with **1.3.0 on the server and all clients**. No separate configuration or resource pack is needed. Do not install the runtime-checks jar.

Code: LGPL-3.0-only. AE2-derived textures and models: CC BY-NC-SA 3.0. Preserve the included notices.

## Русский

Аддон AE2 для Enigmatica 2: Expert 1.93a. Русский и английский выбираются настройкой языка Minecraft.

Исправлены сохранение остатков интерфейса, небезопасная инициализация, загрузка повреждённого NBT ячеек, обработка энергии конвертера, клики контейнеров и нестандартные форматы вершин. Документация подготовлена на двух языках. Версия 1.3.0 заменяет номер подготовленной 1.2.1.

Проверки: 114 регрессионных. Тот же функциональный код до переименования прошёл 1415 игровых и интеграционных проверок и 8192 обращения к моделям из четырёх потоков. Длительная работа сервера полностью не проверялась; ограничения приведены в аудите.

Закройте Minecraft, сделайте резервную копию мира и замените прежний jar на **ae2expert-1.3.0.jar**. Оставьте одну версию аддона; **серверу и всем клиентам нужна 1.3.0**. Отдельные конфиги и ресурспак не требуются. Проверочный runtime-checks.jar не устанавливайте.
