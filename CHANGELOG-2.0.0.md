# 2.0.0

## English

- Sneak-right-click opens the Crafting CPU Rack configuration;

- Wireless hub for up to 128 relays, four relay tiers, linker, names and individually selectable connection overlays.

- Added 13 crafting storage blocks, from 128k to 512 MiB, following the four stock AE2 tiers.
- Added ×9, ×81 and ×729 crafting coprocessors with the original AE2 dispatch rules.
- Added the 18-slot Crafting CPU Rack with support for stock and addon modules and 64 blocks per slot.
- Added English and Russian names, recipes, models and rack UI.
- Included the 1.3.0 fixes for ME interface ingredient delivery, fluid and gas cell filters, Fluix Chamber extraction and accelerated assembler queues.

## Русский

- Shift + ПКМ открывает настройки стойки CPU;
- Беспроводной центр на 128 соединений, четыре тира, связыватель, имена и отдельное отображение линий.
- 13 новых хранилищ создания от 128k до 512 МиБ, продолжающих штатные тиры AE2.
- Блоки обработки создания ×9, ×81 и ×729 со штатным планированием операций AE2.
- Объеденитель CPU создания с 18 слотами по 64 блока для штатных и новых модулей.
- Русские и английские названия, рецепты, модели и окно стойки.
- Включены исправления 1.3.0 для передачи ингредиентов через МЭ-интерфейс, фильтров жидкостных и газовых ячеек, извлечения из камеры и очереди ускоренных сборщиков.
