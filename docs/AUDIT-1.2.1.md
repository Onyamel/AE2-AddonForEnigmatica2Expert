# Проверка логики 1.2.1

Проверка выполнена по текущим исходникам и локальному коду AE2 rv6-stable-7.

| Замечание | Результат |
|---|---|
| Публикация Field в ChannelHook | Подтверждено: volatile и синхронизация разрешения reflection. Доступность выставляется до публикации. |
| Состояние рецептов интерфейса | Обычная многопоточность не подтверждена. Исправлена потеря повторной отметки dirty при синхронном событии AE2. |
| Неограниченный pending | Для крафта следующая задача блокируется уже имеющейся очередью. Найдено смешение остатков пополнения запасов с ингредиентами: введён отдельный recovery, новые пополнения при остатке останавливаются. |
| isBusy и canFit | Отказ при незавершённой выдаче необходим: это обратное давление, а не потеря задания. Очередь не перезаписывается; до canFit непустой pending не допускается. |
| Capability интерфейса | Буфер на всех сторонах — намеренный контракт. Ghost-слоты не являются реальными предметами и не должны выдаваться трубам. |
| Массивы сторон кабеля | Локальные массивы Java обнуляет при каждом вызове. Ошибка залипания из этого участка не следует. |
| Смещение цвета вершин | Добавлены проверки выравнивания, шага и длины массива; неизвестный формат сохраняется без перекраски. |
| Переполнение NBT ячейки | Исправлено. Неразбираемые/переполняющие записи сохраняются отдельно в expertInvalidItems. Подсказка сообщает о необходимости восстановления. Автоматическое восстановление неоднозначных повреждённых записей не выполняется. Улучшение такой ячейки крафтом запрещено. |
| SIMULATE извлечения | Ошибка не подтверждена: изменение уже находится внутри MODULATE. Добавлен тест полного симулированного извлечения. |
| Вложенные контейнеры | Наличие чужой ячейки внутри сериализованного контейнера само по себе не рекурсивный вызов. Код не обходит содержимое чужих контейнеров; прямые ячейки отвергаются. Произвольный разбор чужого NBT не добавлялся. |
| Неиспользуемый matches | Удалён. |
| Дробная конверсия EU→RF | Остаток меньше 1 RF сохраняется в EU-буфере и NBT, а не теряется. Добавлен тест малых конверсий. |
| drawEnergy | Добавлена проверка направления. Это предотвращает неверное списание; утверждение о создании энергии одним только clamp не подтверждено. |
| Жёсткое число ASM-констант | Оставлено намеренно: поддерживается конкретная версия AE2. Ослабление проверки может создать частично преобразованный счётчик. При несовпадении уже выводится ошибка с именем класса и причиной. Другие версии AE2 требуют отдельной проверки. |
| BusModels | Инициализация перенесена в статический инициализатор JVM, исключающий публикацию частично построенных карт. |
| Отрицательные slot id | -999 — штатный клик вне окна, -1 нужен протоколу перетаскивания. Сохранены. Добавлены границы прочих id, сброс перетаскивания при смене вкладки, защита transferStackInSlot и скрытых слотов. |
| Газовые ячейки | Отсутствующая регистрация теперь даёт явную диагностическую ошибку вместо пустого результата. |

Дополнительно исправлена потеря RF из-за округления вверх при заполненном почти до конца EU-буфере. Количество ожидающих предметов передаётся в GUI и показано при наведении на индикатор сети. Новых фоновых потоков и обходов сети не добавлено.

Обе локализации содержат одинаковые ключи. Английские названия и сообщения используют терминологию AE2 (ME Storage Cell, Molecular Assembler, Fluix Crystal, Patterns). Смена языка использует штатную загрузку языковых ресурсов Minecraft.

Резервная копия исходников перед изменениями: backups/before-1.2.1-audit.zip. Рабочие миры не изменялись.

## Проверки

- Сборка JDK 8 / ForgeGradle 2.3: BUILD SUCCESSFUL.
- 114 регрессионных проверок, включая 16 000 параллельных обращений из 8 потоков при первом разрешении reflection.
- 758 игровых проверок базового поведения: реальные сети 32/64/128/256, ячейки трёх каналов, запасы интерфейса, шаблоны и камера.
- 657 проверок возможностей: 648 серверных проверок подключений частей, девяти фильтров шин и коллизий плюс 9 проверок JEI.
- 8192 обращения к настоящим моделям из четырёх потоков: ошибок нет, исходный кэш граней не изменён.
- Локализации: по 104 ключа, совпадают параметры форматирования; русских строк в английском файле нет.

Это ограниченный автоматизированный прогон, а не гарантия отсутствия всех багов во всех сборках. Повреждение сторонних инвентарей, произвольные контейнеры других модов и длительная работа многопользовательского сервера полностью не моделировались. Ручная проверка всех экранов на обоих языках не выполнялась.
